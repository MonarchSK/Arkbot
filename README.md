RequirementsPython 3.10 or newerA registered Discord Bot Application with Privileged Gateway Intents enabled:Message Content IntentServer Members Intent2. DependenciesInstall the required packages:Bashpip install -U discord.py
3. Environment VariableExport your Discord bot token:Bash# Linux / macOS
export DISCORD_BOT_TOKEN="your_bot_token_here"

# Windows (Command Prompt)
set DISCORD_BOT_TOKEN=your_bot_token_here

# Windows (PowerShell)
$env:DISCORD_BOT_TOKEN="your_bot_token_here"
4. Running the BotBashpython bot.py
